# Data Guide

가정통신문 문장에서 학부모가 확인하거나 행동해야 하는 핵심 정보를 추출하고 분류하기 위한 데이터입니다.

## 데이터 파일

| 파일 | 설명 |
| --- | --- |
| `raw/` | 원본 가정통신문 텍스트 보관 위치 |
| `labeled/notice_sample_v1.csv` | 초기 샘플 데이터 30개 |
| `labeled/notice_sample_v2.csv` | 확장 샘플 데이터 200개 |
| `labeled/notice_sample_v3.csv` | 유치원 비중을 높인 비교용 샘플 데이터 200개 |

## notice_sample_v2 구성

- 전체 샘플 수: 200개
- 초등학교: 150개, 75%
- 유치원: 50개, 25%
- 행 순서는 특정 기관이나 카테고리별로 정렬하지 않고 섞어서 저장합니다.
- `vietnamese` 컬럼은 번역 결과를 저장하기 위한 컬럼이며, 일부 샘플은 추후 번역 보강 대상으로 비워둘 수 있습니다.

## notice_sample_v3 구성

- 전체 샘플 수: 200개
- 초등학교: 120개, 60%
- 유치원: 80개, 40%
- `notice_sample_v2.csv`보다 유치원 문장 비중을 높인 비교용 데이터입니다.
- 유치원 안내문 분류 성능을 더 보고 싶을 때 사용합니다.
- 행 순서는 특정 기관이나 카테고리별로 정렬하지 않고 섞어서 저장합니다.

## 주요 카테고리

| 카테고리 | 예시 |
| --- | --- |
| `일정` | 현장학습, 소풍, 상담, 평가, 운동회, 졸업식 |
| `준비물` | 도시락, 물병, 실내화, 체육복, 수영복, 여벌옷 |
| `제출` | 동의서, 신청서, 조사서, 확인서, 활동지 |
| `비용` | 체험학습비, 급식비, 방과후 수강료, 앨범비 |
| `건강·안전` | 건강검진, 감염병, 미세먼지, 교통안전, 대피훈련 |
| `기타` | 생활 안내, 홈페이지 확인, 규칙 안내, 참고 정보 |

## 중요도 기준

| 값 | 의미 |
| --- | --- |
| `1.0` | 제출 기한이 있거나 바로 행동이 필요한 매우 중요한 안내 |
| `0.9` | 준비물, 제출, 납부처럼 놓치면 문제가 생길 수 있는 안내 |
| `0.7` | 일정 확인이나 가정 지도처럼 확인이 필요한 안내 |
| `0.5` | 생활 안내, 학습 안내 등 참고 성격의 정보 |
| `0.3` | 일반 공지 수준의 낮은 중요도 정보 |

## 라벨링 컬럼

```csv
id,source_type,original_text,category,keywords,importance,action_required,easy_korean,vietnamese,tts_target
```

| 컬럼 | 설명 |
| --- | --- |
| `id` | 샘플 번호 |
| `source_type` | 문서 출처 유형, 예: `초등학교`, `유치원` |
| `original_text` | 원본 안내 문장 |
| `category` | 문장의 주요 분류 |
| `keywords` | 핵심 키워드, 여러 개일 경우 `|`로 구분 |
| `importance` | 중요도 점수 |
| `action_required` | 학부모 행동 필요 여부, `Y` 또는 `N` |
| `easy_korean` | 쉬운 한국어 요약 문장 |
| `vietnamese` | 베트남어 번역 문장 |
| `tts_target` | 음성 안내 대상 여부, `Y` 또는 `N` |
