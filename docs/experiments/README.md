> 모델·전처리·데이터·추론 파이프라인의 모든 정량 비교 실험을 한 곳에 추적합니다.
> 강사 피드백(2026-04-28): *"성능 비교에 대한 정량 지표는 인공지능에서 가장 중요한 태스크.
> 객관적 근거 마련, 방향 수립, 보고서, 제3자 설명을 위해 반드시 실험 노트로 기록해 달라."*

## 작성 규칙

- 실험 1건 = 파일 1개. 파일명: `YYYY-MM-DD-{영역}-{짧은이름}.md`
- 모든 실험은 **`template.md`** 양식을 따름 (데이터 / 전처리 / 모델 / 하이퍼파라미터 / 결과 / 인사이트)
- 새 실험 추가 시 본 `README.md`의 인덱스 표에도 한 줄 추가

## 영역 분류

| 약어 | 영역 |
| --- | --- |
| `extraction` | 추출 모델 (윤정 KoELECTRA) |
| `classification` | 분류·중요도 모델 (경이) |
| `translation` | 번역 + 사전 검수 (세종 NLLB) |
| `tts` | 음성 출력 (세종 Edge-TTS) |
| `data` | 데이터셋 라벨/검증/증강 |
| `pipeline` | E2E 통합 |

## 향후 실험 후보

- [ ] 데이터 추가 (민경이님 가상 데이터) 후 추출 모델 3차 학습 — 준비물·기타 F1 ≥ 0.70 목표
- [ ] 윤정 KoELECTRA 이진분류 분리 + 경이 6분류 모델 메인화 후 비교
- [ ] NLLB max_length 256 → 512 → 1024 — 잘림 현상과 품질 변화
- [ ] 사전 size 144 → 200 → 300 — 사전 효과 한계점
- [ ] LLM 검수 자동화 (반자동 등록 흐름) 적용 전후 사전 품질
