## 6. 인사이트 / 해석

- **NLLB 단독 평균 33.9점** — 일반 번역기로는 학교 도메인 용어가 부정확하거나 빠짐. 8개 언어 모두 일관됨.
- **사전 적용 후 평균 100점은 평가가 헐거운 결과.** 세종 본인이 *"100점은 좀 오바인 것 같다"*고 평가 프롬프트 타이트화 후 재측정 예정. → **본 1차 수치는 보정 전 보수적 해석 필요.**
- **A/B 비교에서 B 평균 +11.8점**은 max_length=256 잘림 패널티 포함된 보수치. 운영 백엔드(512)에서는 잘림 줄어들어 더 좋아질 가능성.
- **Gemini 공통 지적**: *"문장이 중간에 잘림 — max_length=256 제한 때문"* → 운영에서는 max_length 늘려야 함 (백엔드 `translator.py:_translate(max_length=512)` 이미 적용 완료).

## 7. 보정 후 재측정 (2026-04-28 오후)

1차 측정 이후 아래 두 가지를 보완해 재측정했다.

- NLLB 입력/출력 길이 문제: 문장 단위 청크 번역 + `max_new_tokens` 기반 생성으로 중간 잘림 완화.
- Gemini 평가 기준: 단순 용어 포함 여부가 아니라 현지 상용 표현, 학교 문맥 자연스러움, 정보 보존, 한국어 의미 역번역(Round-trip) 기준 추가.

### 용어사전 전/후 품질 재평가

| 항목 | 1차 측정 | 보정 후 |
| --- | ---: | ---: |
| NLLB 단독 평균 | 33.9 | 39.0 |
| 사전 적용 평균 | 100.0 | 89.6 |
| 향상폭 | +66.1 | +50.6 |

보정 후에도 용어사전 적용 효과는 유지되지만, 100점 몰림은 사라졌다. 특히 `현지에서 실제로 쓰이는 표현인지`와 `역번역 시 원문 핵심 정보가 유지되는지`를 함께 보게 되어 더 현실적인 점수로 조정됐다.

### 언어별 재평가 결과

### A/B 품질 재평가

| 항목 | 1차 측정 | 보정 후 |
| --- | ---: | ---: |
| A: 원문 전체 번역 | 33.3 | 50.1 |
| B: TODO만 번역 | 45.1 | 54.1 |
| B 우세 폭 | +11.8 | +4.0 |

보정 후 평가는 더 엄격하다. B가 평균적으로는 여전히 높지만, 원문 전체 맥락이 필요한 문서에서는 A가 더 높게 나오는 케이스도 확인됐다. 18건 전수 기준으로 B 우세 6건, A 우세 6건, 동등 6건이다.

### Round-trip 전수 검사

18개 공지 전체에 대해 번역문을 다시 한국어로 의미 역번역해 검사했다.

| 항목 | 결과 |
| --- | ---: |
| A: 원문 전체 번역 평균 | 50.1 |
| B: TODO만 번역 평균 | 54.1 |
| B 우세 | 6건 |
| A 우세 | 6건 |
| 동등 | 6건 |

반복 왜곡 유형은 아래와 같다.

| 유형 | 예시 |
| --- | --- |
| 준비물 오역 | 리코더→녹음기, 돗자리→핸드백, 필통→티셔츠 |
| 안전 문맥 왜곡 | 우범지역→좋은 지역, 장난 사용→가구 사용 |
| 날짜/학년 오정보 | 3월 5일→5월 9일, 6학년→3학년 |
| 대상 오역 | 학생/초등학생→대학생, 보호자→경비원 |
| 고유명사 오역 | 학교종이→학교들, 갈산→Gaul |

대표 예시는 `N02 초등안심벨`이다.

| 항목 | 점수 | 역번역으로 잡힌 문제 |
| --- | ---: | --- |
| A: 원문 전체 | 45 | 본문 후반 누락, 안심벨 오역, 학생 대상 왜곡 |
| B: TODO만 | 72 | `장난 사용 주의`가 `가구 사용 주의`로 왜곡, `어깨끈`이 `손목끈`으로 왜곡 |

이 방식은 겉보기에는 외국어 문장처럼 보여도 실제 안내 의미가 틀어진 경우를 잡아낼 수 있다.
