## 6. 인사이트 / 해석

- **추출 효과는 "안내 공지" 영역에서 강하게 작동.** 전체 텍스트의 본질이 *"맥락 설명 + 행동 항목"*인 가정통신문에서 행동 항목만 추출 시 입력이 크게 줄고 NLLB 추론 시간 단축.
- **주간학습계획 / 알림장에서는 효과가 사라지거나 역전됨.** 이런 텍스트는 본문 전체가 거의 행동 항목이라 추출 자체가 비용. → *피처 추출 도구의 적용 영역이 명확*.
- **N08 도서구입 ×4.98이 최대값** — 입력 -78.6%로 NLLB가 처리할 토큰이 거의 1/5로 줄어든 케이스.
- max_length=256 환경에서 측정한 1차 보수적 수치. 이후 세종 파트 실험 스크립트는 문장 단위 청크 번역 + `max_new_tokens` 기반 생성으로 보완했다.
