# MVP 정의서 및 체크리스트 — 가정통신문 AI 도우미

## 서비스 한 줄 정의

베트남 결혼이민 학부모가 가정통신문을 입력하면 "오늘 해야 할 일"만 체크리스트로 정리하고,
한국어 수준에 맞춰 베트남어 또는 한국어 음성으로 안내해주는 서비스

---

## MVP 범위

### 포함 (In Scope)

| 기능 | 설명 | 담당 |
| --- | --- | --- |
| 가정통신문 텍스트 입력 | 앱에서 직접 텍스트 입력 | 찬영 |
| 할 일 추출 | 준비물·일정·제출·비용 문장 추출 | 윤정 |
| 카테고리 분류 + 중요도 | 6개 카테고리 + 0~1 점수 | 민경 |
| 베트남어 번역 | 교육 용어 포함 번역 | 세종 |
| TTS 음성 안내 | 초급: 베트남어 / 중급: 한국어 | 세종 |
| 사용자 프로파일 | 한국어 수준·학년 저장 | 태수 |
| Android 데모 앱 | 실기기 시연 가능 | 찬영 |
| FastAPI 서버 | 모델 연결·API 제공 | 태수 |

| 기능 | 제외 이유 |
| --- | --- |

| STT 음성 질문 | 후순위 |
| 담임 문자 전달 | 후순위 |

## MVP 체크리스트

### 목표

핵심 기준 3가지:
1. 실제로 동작하는 흐름이 있다
2. 베이스라인 모델 실험 결과가 있다
3. MVP 범위와 한계가 문서화되어 있다

---

### 데이터 (세종)

- [ ] 라벨 체계를 6개로 확정한다
- [ ] 라벨 정의를 문서로 정리한다
- [ ] 목표 샘플 수를 약 150개로 맞춘다
- [ ] `기타` 라벨 기준을 명확히 정리한다
- [ ] `importance`, `action_required`, `tts_target` 기준을 통일한다
- [ ] 학습/검증용으로 나눌 수 있게 데이터 구조를 정리한다

### 베이스라인 모델 (민경·윤정)

- [ ] 분류용 베이스라인 모델을 선정한다
- [ ] 6개 라벨 기준으로 학습 또는 추론 실험을 진행한다
- [ ] 예측 결과 예시를 3개 이상 확보한다
- [ ] 성능 지표를 정리한다
- [ ] 결과 해석 문장을 준비한다

### 서버 (태수)

- [x] FastAPI 서버가 실행된다
- [x] `/health` 응답이 정상이다
- [x] 분석용 엔드포인트가 동작한다
- [x] 결과 JSON 구조가 정리되어 있다
- [ ] Android에서 붙일 수 있는 응답 예시가 있다

### 번역 / TTS (세종)

- [ ] 쉬운 한국어 출력 형식이 정리되어 있다
- [ ] 베트남어 번역 결과를 확인할 수 있다
- [ ] TTS 버튼 또는 음성 재생 흐름이 있다
- [ ] 데모에서 사용할 예시 문장을 준비한다

### 디바이스 데모 (찬영)

- [ ] 실기기에서 앱이 실행된다
- [ ] 공지사항 텍스트를 입력할 수 있다
- [ ] 분석 결과를 카드 또는 리스트 형태로 볼 수 있다
- [ ] 쉬운 한국어 요약이 보인다
- [ ] 베트남어 번역이 보인다
- [ ] TTS 버튼이 동작하거나 동작 흐름이 확인된다
- [ ] 발표용 데모 시나리오를 1개 이상 정리한다

### 문서

- [x] 루트 `README.md`가 현재 방향과 맞게 정리되어 있다
- [ ] `data/README.md`가 6개 라벨 기준과 맞는다
- [x] 팀 브리프 문서가 정리되어 있다
- [x] 트러블슈팅 문서가 작성되어 있다
- [x] MVP 정의와 제외 범위가 정리되어 있다

### 발표 준비

- [ ] 프로젝트 핵심 문제를 한 문장으로 설명할 수 있다
- [ ] 왜 학교 알림에 먼저 집중하는지 설명할 수 있다
- [ ] 왜 6개 라벨로 시작했는지 설명할 수 있다
- [ ] 향후 확장 방향을 한 문장으로 설명할 수 있다
- [ ] 실기기 데모 순서를 팀 내에서 맞춘다
