### 2. 학부모 PDF 직접 업로드 구현

기존 학부모 홈 버튼 4개(수신함/OCR/빈 버튼/로그아웃) → 3개로 정리.

**추가된 구성요소:**

| 메서드 | 역할 |
|--------|------|
| `showUploadDialog()` | "사진으로 찍기 / PDF 파일 올리기" 다이얼로그 |
| `launchFilePickerParent()` | SAF 파일 피커 (PDF·TXT) |
| `uploadSelfFile()` | 파일 읽기 → `postMultipartUploadSelf` → 완료 시 `loadInbox()` |
| `postMultipartUploadSelf()` | `POST /notice/upload-self` multipart 업로드 |

**연동 엔드포인트**: `POST /notice/upload-self` (헤더 `X-User-Id: parent_id`)

**요청 코드**: `REQUEST_PICK_FILE_PARENT = 1003`

### 3. `vi_demo` STT 답변 한국어 수정

**문제**: 시연용 `vi_demo`에서 STT 답변이 베트남어로 출력됨

**원인 1** — `buildSpokenText()` 에서 `value_translated`(베트남어)를 우선 사용  
**원인 2** — `speakText()` 에서 `vi_demo`를 `vi-VN` 로케일로 처리

**수정:**

```java
// buildSpokenText()
boolean useKo = "vi_demo".equals(selectedLanguage);
String val = useKo
    ? safeString(card, "value_ko")
    : firstNonBlank(safeString(card, "value_translated"), safeString(card, "value_ko"));

// speakText()
case "vi":      locale = new Locale("vi", "VN"); break;
case "vi_demo": locale = Locale.KOREAN;          break;
```
