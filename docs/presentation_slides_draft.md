## 3. §1 프로젝트 개요 (5필수 항목)

```
■ 1. 프로젝트 주제 및 선정 배경 / 기획의도
   • 주제: 학부모 알림장 앱(학교종이·하이클래스·e알리미) 탑재용
            가정통신문 도메인 특화 AI 엔진 + AI 능력 시연용 안드 데모 앱
   • 배경: 다문화 초등학생 11.7만 명 (2025), 13년 3.5배 증가
            결혼이민자 한국어 평균 3.89/5 — 읽기·쓰기 가장 약함
            기존 알림장 3대장 모두 가정통신문 자체 처리·정보 구조화 X
   • 기획의도: 알림장 3대장에 합쳐서 다문화 가정 정보 격차 해소

■ 2. 특화 포인트 / 기존 유사 서비스 차별화
   • 알림장 3대장 (학교종이·하이클래스·e알리미): 한국어 단순 송수신
       → SchoolBridge: 가정통신문 도메인 특화 AI 엔진 탑재
   • 범용 번역기 (파파고·ChatGPT): 평이한 텍스트 정확
       → SchoolBridge: 학교 행정 어휘 글로사리 보존 (340여 항목)
                       + 6칩 자동 분류 + 슬롯 추출
   • 거대 LLM "한 번의 답" → SchoolBridge "학부모의 일주일 관리"
       (누적 체크리스트 · 캘린더 · TTS · STT · FCM 푸시)

■ 3. 프로젝트 구현 내용 / 컨셉 / 훈련 연관성
   • 자체 모델 3개 + LLM normalizer 임시 1단계
     · KoELECTRA (슬롯) / KcELECTRA (분류) / NLLB+글로사리 (번역)
     · Claude Haiku 4.5 (sentence 추출, 자체화 목표)
   • 풀스택: FastAPI 백엔드 + Android 앱 + NCP CPU 서버
   • 훈련 연관: NLP·딥러닝·CV·풀스택 서비스 디자인 종합

■ 4. 활용 장비 / 재료 / 개발환경
   • 데이터: 8개 학교 가정통신문 3,300+ 장 + 라벨링 6만+ 행
   • 모델: PyTorch + transformers + HF Hub + Mecab
   • 인프라: NCP CPU 서버 + Docker + Firebase Cloud Messaging
   • 안드: Android minSdk 23, ML Kit OCR, OpenCV, SpeechRecognizer

■ 5. 활용방안 / 기대 효과
   • 배포 형태: 알림장 3대장에 API/SDK 형태로 탑재
   • 학부모: 9개 언어 + 6칩 분류 카드 + 누적 관리 → 학교 정보 격차 해소
   • 학교: 별도 번역 인력 없이 다문화 가정 안내 가능
   • 정책: 다문화 학생 적은 일반 학교의 소수 가정 사각지대 해소
   • 향후: STT 음성 검색 + 캘린더 통합 → 다문화 가정 행정 비서로 확장
```

## 5. §1.6 어휘 격차 학술 실증 — "한국어 시험 만점도 안 풀리는 문서" ⭐

```
■ 핵심 명제 — 한국어 일상 회화 능숙해도 가정통신문은 별개의 장벽
   • 한국어 능숙한 중국 동포 여성도 가정통신문 이해 어려움
       — 조선경 (2006)
   • 결혼이민자 50% 이상 "한국어 이해 어려움"으로 자녀 숙제 곤란
       — 우희숙 (2009)
   • 심층 면접 결혼이민자 10명 전원이 학부모 역할 한국어 교육 희망
       — 공지연·심혜령 (2009)

■ 그런데 교육 받을 여력 없는 구조적 현실 (여가부 2024 실태조사)
   • 결혼이민자·귀화자 고용률 62.7% — 여성은 여성 일반 +2.7%p
       → 한국 여성보다 더 일하는 비율
   • 직종 분포: 단순노무 39.0% + 서비스 21.4%
       → 결혼이민자 60%가 단순노무·서비스직 (식당·공장·청소 등)
   • 임금 300만원 미만 약 80% / 임시·일용 근로자 37%
   • "집안일 병행 어려움" 매년 증가 추세 — 일·가사·육아 동시 부담
   • 한국어교육 서비스 이용 경험: 9.7% (욕구 1위인데도 10명 중 1명)

   ⇒ 교육 받고 싶어도 시간·여력 부족 → 가정통신문은 "독학으로 풀어야 할 숙제"

■ 코퍼스 실증 ─ 표준 한국어 교재로 안 풀리는 어휘 비율
   서울 16개 초등학교 가정통신문 2,094편 → 빈도 어휘 1,687개 추출
   (오지연 2017, 경인교대 한국어교육 석사학위 논문)

   ┌────────────────────────────────────────┬──────────┬─────────┐
   │  대조 어휘 자료                        │  어휘량  │ 일치율  │
   ├────────────────────────────────────────┼──────────┼─────────┤
   │  국립국어원 한국어 학습용 어휘 (2003)  │  5,965   │   46%   │
   │  국제통용 한국어 표준 모형 (2011)      │ 11,116   │   63%   │
   └────────────────────────────────────────┴──────────┴─────────┘

   → 가정통신문 어휘의 37%는 어떤 표준 한국어 교재에도 없음
   → 학교 특수 어휘 예시 216개:
     스쿨뱅킹 · 방과후학교 · 돌봄교실 · 차상위계층 · 나이스 · 드림레터
     자유학기제 · 수행평가 · 현장체험학습 · 차시 · 학교운영위원회 ···

■ 가정통신문 어휘 구성 (김점순 2018, 조선대)
   품사 분석 → 명사 60% / 고빈도 어휘:
   학부모 · 자녀 · 안내 · 신청 · 참가 · 봉사활동 · 제출하다 · 운영 ···
   → 우리 시스템이 카드로 추출하는 항목과 데이터 기반 정합

═══════════════════════════════════════════════════════════════
■ SchoolBridge 의 접근 — "아직은 뒤지지만, 핵심은 잡고 계속 학습 중"

   일반 번역 정확성은 거대 LLM/파파고가 아직 우위 — 정직하게 인정.
   우리는 작은 자체 모델로 시작했지만, 학부모가 놓치면 안 되는
   핵심 정보부터 잡고, 도메인 데이터 누적으로 격차 좁히는 중.

   ① 핵심 정보부터 잃지 않게 잡음 (실측치)
      • 날짜·금액·URL·전화번호 슬롯 보호: 21/21 PASS
      • 학교 행정 용어 글로사리 보존: 1/17 → 17/17 (확장 37/37)
      • 도메인 글로사리 없이는 학교 행정 어휘 보존이 어려움
        → 우리는 340여 항목 글로사리로 핵심 어휘부터 잡음

   ② 데이터로 계속 따라잡는 중
      • 8개 학교 3,300+장 · 6만+ 라벨링 행 누적
      • KoELECTRA · KcELECTRA 자체 파인튜닝 (47,148 + 15,948행)
      • NLLB-200 사전학습 + 글로사리 319개 + 슬롯/템플릿 보호 파이프라인
      → 도메인 데이터·글로사리 늘수록 일반 정확성도 함께 끌어올리는 중

   ③ 학부모 앱 통합 서비스 (단순 번역 텍스트와 다른 차원)
      • 쉬운 한국어 + 9개 언어 + 6칩 분류 + 슬롯 카드
      • 캘린더 · 누적 체크리스트 · TTS·STT · FCM 푸시 · 자동 로그인
      → 거대 LLM "한 번의 답"이 아닌 "학부모의 일주일 관리"

   ⇒ 한국어 교육 없이도 폰으로 즉시 확인 + 가정통신문 전용 도구
```

## 6. §1.7 시장 위치 — 경쟁 분석 + 우리 유일 영역 ⭐

```
■ 시장 진입 전략 — "맞붙지 말고 합쳐라"

  ▸ 알림장 3대장 (하이클래스 · e알리미 · 학교종이)
    = 우리 경쟁자 X · 우리 잠재 고객 ○
  ▸ SchoolBridge = 3대장에 탑재되어 빈 자리
    (다국어 도메인 특화 · 정보 구조화)를 채우는 AI 엔진
  ▸ 안드 데모 앱 = AI 능력 시연용 (실제 배포는 탑재 형태)

■ 시장 전수 조사 (13개 서비스 프로파일)

  ① 범용 번역 — 파파고 · 구글 번역 · ChatGPT
     · 다국어 ✓ (130개+) · 정확도 우위 · BUT 학교 도메인 어휘 손실
     · 파파고 한계: 문서 번역(HWP/PDF) **한→영 1개만** · 이미지 번역 **유료**
       → 다문화 가정 학부모가 사진 통신문을 모국어로 자동 변환 X
  ② 일반 알림장 앱 — 학교종이 · 하이클래스 · 아이엠스쿨 · 클래스팅 · 키즈노트
     · 송수신 ✓ · 일부 다국어 (수동 클릭 or 텍스트 입력만)
     · BUT 사진/PDF/HWP 자체 처리 X · 정보 구조화 X
  ③ AI 통합 알림장 — 스쿨포인트 (KUSITMS 출신, 운영 중)
     · CLOVA OCR + ChatGPT API · 요약·투두 ✓
```
