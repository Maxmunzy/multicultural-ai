## 슬라이드 흐름 (5장)

```
1️⃣ 국제결혼 연도별 추이        → 시장 크기
```

## 1. 국제결혼 연도별 추이

### 출처
- **통계청 KOSIS** — 인구동향조사 → 외국인과의 혼인
- 메인: <https://kosis.kr>
- 검색 키워드:
  - "국제결혼"
  - "외국인 배우자 혼인 건수"
  - "외국인과의 혼인"

### 그래프 형식 권장
- **라인 차트** — 가로축: 연도, 세로축: 혼인 건수
- 코로나 급감(2020) / 회복 구간 등 변곡점 표시

## 2. 배우자 국가 순위

### 출처
- **통계청 KOSIS** — 한국인 배우자 외국인 국적별 혼인
- 메인: <https://kosis.kr>
- 검색 키워드:
  - "외국인 배우자 국적별"
  - "결혼이민자 국적"
  - "다문화가족 국적별"

### 그래프 형식 권장
- **가로 막대** 또는 **파이 차트** — 상위 5~10개국 + 기타
- 우리 9개 언어 매핑 표 함께 노출

### 우리 시스템 9개 언어
| 코드 | 언어 |
|---|---|
| vi | 베트남어 |
| zh | 중국어 |
| th | 태국어 |
| ja | 일본어 |
| en | 영어 |
| ru | 러시아어 |
| ms | 말레이시아어 |
| mn | 몽골어 |
| ko_easy | 쉬운 한국어 |

## 3. 다문화 학생 증가 추이

### 출처
- **교육부 / 한국교육개발원 KESS** — 교육통계서비스
- 메인: <https://kess.kedi.re.kr>
- 검색 키워드:
  - "다문화학생"
  - "다문화학생 통계"
  - "초중고 다문화 학생 수"
- 보조: **교육부 보도자료** — "교육기본통계 발표" (매년 8~9월경)

### 그래프 형식 권장
- **라인 차트** — 가로축: 연도, 세로축: 학생 수
- 또는 면적 차트로 누적 증가 강조

## 4. 다문화 학부모 한국어 능력 ★

### 출처
- **여성가족부 전국 다문화가족 실태조사** (3년 주기)
- 메인: <https://www.mogef.go.kr>
- 자료실 → 통계 / 조사보고서
- 검색 키워드:
  - "전국 다문화가족 실태조사"
  - "다문화가족 한국어"
  - "결혼이민자 한국어 능력"

### 그래프 형식 권장
- **도넛 차트** (한국어 수준별 비율) 또는 **가로 막대**

## 5. 통신문·학교 참여 어려움 ★★

### 출처
- **여성가족부 전국 다문화가족 실태조사** (학교 참여 / 자녀 양육 항목)
- **교육부 / 한국교육개발원 다문화학생 종단연구**
- 검색 키워드:
  - "다문화 학부모 학교 참여"
  - "다문화 학부모 가정통신문"
  - "다문화가족 자녀 학교생활"

### 그래프 형식 권장
- **막대 비교** (일반 학부모 vs 다문화 학부모 학교 참여율)
- 또는 **인포그래픽** (사람 아이콘 + 비율)

## 작업 순서 (PPT 만들 때)

1. ☐ KOSIS 사이트 → 1번·2번 데이터 CSV 다운로드
2. ☐ KESS 사이트 → 3번 데이터 다운로드
3. ☐ 여성가족부 PDF 보고서 → 4번·5번 수치 정리
4. ☐ Excel / Google Sheets / matplotlib로 그래프 작성
5. ☐ 슬라이드에 캡처 + 한 줄 요약 텍스트

- **빠른 작업**: Excel / Google Sheets
- **일관 디자인**: Python matplotlib / seaborn
- **PPT 직접**: 슬라이드 안에서 차트 작성 (수정 편함)
