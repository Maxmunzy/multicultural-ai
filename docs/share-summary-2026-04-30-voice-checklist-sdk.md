# 핸즈프리 음성 체크리스트 SDK — 방향 제안

작성: 태수 / 2026-04-30
공유 대상: 팀원

---

## 한 줄

> 통신문을 핸즈프리로 듣고, 음성 한 마디로 가족 체크리스트로 변환해서 시각 채널 열린 시간에 처리할 수 있게 하는, 호스트 학교 앱(하이클래스 등)에 합쳐지는 SDK.

---

## 왜 이 방향인가

강사님 주제 1번(개인화 STT/TTS)에 우리 MVP를 어떻게 정합시킬지 며칠 고민하면서 여러 시도를 했고, 실패한 패턴이 명확해졌습니다:

| 시도 | 실패 이유 |
|---|---|
| "다문화 학부모는 한국어 못 읽으니 TTS 필요" | 모국어로 텍스트 번역해주면 글로 읽으면 됨. TTS 굳이? |
| "학부모→선생님 답장 STT" | 모국어 텍스트 입력이 더 정확하고 검증 가능 |
| "선생님 음성 입력" | 선생님 워크플로우 절대 안 바뀜. 다문화 학부모 1-3명 위해 음성 녹음 안 함 |
| "자녀 voice clone TTS" | 미성년자 음성 동의 이슈 + 정보 전달엔 누구 목소리든 무관 |
| "발음 코치" | 학부모가 발음 연습할 시간/의지 거의 없음 |

→ 모두 **STT/TTS를 어떻게든 쓰려고 끼워맞춘** 시도였습니다.

## 진짜 페인 재정의

다문화 학부모는 **글을 못 읽는 게 아니라 읽을 시각·시간이 없을 때**가 더 많습니다.

- 워킹맘 비율 높음 (식당/공장/돌봄 노동)
- 출퇴근/운전/요리/육아 중 알림 받음
- 그 순간 시각 채널 자체가 닫혀 있어서 텍스트 번역이 아무리 좋아도 못 봄 → 묵혀두다 놓침
- 한국 학부모도 같은 페인이라 카톡 음성변환 잘 씀. 다문화면 더 심함

**즉 텍스트 번역 품질의 한계가 아니라 텍스트 채널 자체의 한계에서 출발하는 페인**입니다. 이 자리엔 음성이 끼워맞춤 없이 자연스럽게 들어갑니다.

## SDK 정의

호스트 앱(하이클래스 등)에 합쳐져, 통신문 정보를 시각 채널 닫힌 순간에도 청각으로 받고 짧게 처리할 수 있게 하는 SDK. 텍스트 UI는 그대로 두고 **핸즈프리 모드만 추가**.

**핵심 가치:** 한 번 듣고 끝이 아니라, 음성 한 마디로 **가족 체크리스트**로 영구 변환 → 시각 채널 열린 시간에 하나씩 처리.

## 모듈 3개

### ① 통신문 풀 음성 브리핑 (TTS)

알림 도착 → 핸즈프리 감지 시 통신문 모국어 전체 음성 자동 재생.

> "5월 3일 체험학습이 있어요. 도시락이랑 물병이 필요하고, 동의서를 5월 1일까지 제출해주세요. 체험학습비는 15,000원이고 5월 5일까지 스쿨뱅킹으로 납부해주세요."

길이 모드: 핵심만 / 표준 / 전체

### ② 음성 체크리스트 (STT + TTS) ← 핵심 모듈

음성 한 마디로 추출된 슬롯을 체크리스트로 변환.

```
사용자: "체크리스트 저장해줘"

자동 생성:
- [ ] 5/1까지 동의서 제출
- [ ] 5/3 체험학습 도시락 + 물병
- [ ] 5/5까지 스쿨뱅킹 15,000원 납부
```

음성 편집 (핸즈프리):

- "동의서 처리됐어" → 체크
- "도시락 김밥으로 메모 추가" → 항목 메모
- "스쿨뱅킹 빼줘" → 제거
- "오늘 할 일 알려줘" → 마감 가까운 항목 음성 안내

### ③ 핸즈프리 짧은 답장 (STT) — 옵션

"확인했어" → 호스트 앱 메시지 채널로 acknowledgment 자동 전송.
긴 답장은 텍스트 입력이 더 낫다는 결론이라 STT는 acknowledgment 수준만.

## 기존 시스템·팀원 아이디어와 연결

| 우리/팀 자산 | 체크리스트 SDK에서 어떻게 살아남는가 |
|---|---|
| `card_builder.py` 슬롯 추출 (header/value) | 슬롯 → 체크리스트 항목 자동 변환 |
| 마감일/카테고리/중요도 | 체크리스트 정렬·필터 기준 |
| 모국어 번역 | 체크리스트 항목 모국어 표시 |
| (팀원 안) 학부모 행동 카드 | 체크리스트 항목 = 행동 카드 그 자체 |
| (팀원 안) 오늘 해야 할 일 정렬 | "오늘 할 일 알려줘" 음성 트리거 |
| (팀원 안) 마감 임박 알림 | 핸즈프리 모드에서 모국어 음성 푸시 |
| (팀원 안) 카테고리별 듣기 | 체크리스트 카테고리 필터 |
| (팀원 안) 검토 필요 자동 표시 | 체크리스트 항목에 review_required 플래그 |

→ 팀원분들 아이디어가 충돌 없이 다 흡수됩니다.

## 트리즈 매핑 (강사님 요구)

| 특성 | 원리 | 해소한 모순 |
|---|---|---|
| 시각 닫힘 → 음성 자동 활성 | #15 동적성 | 텍스트 정확함 ↔ 시각 채널 닫힘 |
| 통신문 → 체크리스트 항목 추출 | #2 추출 | 전체 vs 부분 |
| 들으면서 미리 액션 저장 → 나중 누락 방지 | #9 사전 반대작용 | 정보 받음 ↔ 행동까지 시간차 |
| TTS 듣기 + STT 명령을 한 흐름에 | #5 통합 | 새 시스템 ↔ 기존 NLP 결과 활용 |
| 사용자 명령 패턴 학습 | #25 셀프서비스 | 표준 모델 부정확 ↔ 개인 데이터 적음 |

원리 5개 자연스럽게 매핑.

## 주제 1번 "개인화 STT/TTS" 부합

| 강사님 주제 1번 예시 | 우리 매핑 | 강도 |
|---|---|---|
| 특정 발화 특성에 최적화된 STT | 학부모 모국어 + 한국어 코드스위칭 + 학교 도메인 + 사용자 명령 패턴 어댑터 | **강** |
| 사용자 맞춤형 음성 비서 | 가족 컨텍스트(자녀 이름·학교·학년) 인지하는 음성 체크리스트 시스템 | **강** |
| 사용자 말투/속도/억양에 맞춘 TTS | 속도·모국어 방언 옵션. voice clone은 본인 선택만 | 약 |

→ STT + 시스템 측 강 매핑. TTS 측은 정직하게 약하다고 인정. 발표 임팩트는 STT/체크리스트 데모로.

## 시연 시나리오 (BEFORE / AFTER)

**BEFORE (현재):** 출근길 통신문 알림 → 운전 중이라 못 봄 → "이따 봐야지" → 까먹음 → 자녀 통해 뒤늦게 알게 됨 → 자녀 부담

**AFTER:**

1. 알림 도착 → 핸즈프리 자동 감지 → 모국어 풀 브리핑 (운전 중 듣기)
2. "체크리스트 저장" (모국어 음성)
3. 4개 항목 자동 정리
4. 점심에 폰 보고 동의서 처리 → "동의서 했어" 음성 체크
5. 퇴근 후 스쿨뱅킹 → "스쿨뱅킹 했어" 체크
6. 자기 전 도시락 준비 → "도시락 했어" 체크

→ 정보 손실 0, 행동 누락 0, 자녀 부담 0.
