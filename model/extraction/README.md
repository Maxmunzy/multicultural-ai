# 모델 A: 할 일 추출 및 통합 분류 (Extraction & Classification)

> **담당: 윤정**
> **위치:** `model/extraction/`
> **핵심 기능:** 가정통신문 원문에서 학부모가 해야 할 '할 일(To-Do)'을 추출하고, 카테고리 분류 및 중요도를 한 번에 산출

---

## 1. 개요
선생님이 보낸 긴 가정통신문 텍스트에서 학부모가 즉각적으로 확인해야 할 **핵심 행동 지침**을 뽑아냅니다. 단순히 문장을 찾는 것을 넘어, 태수님의 서버 스키마에 맞춰 데이터를 구조화(JSON)하는 역할을 합니다.

## 2. 기술 스택
- **사용 모델:** `Llama-3-Korean-8B-Instruct` (Few-shot 방식)
- **구동 환경:** Google Colab (T4 GPU 활용)
- **기법:** 4-bit 양자화(BitsAndBytes) 및 프롬프트 엔지니어링

## 3. 핵심 전략: Few-shot 통합 추출
별도의 무거운 파인튜닝 대신, 똑똑한 LLM에게 정답 예시를 보여주는 **Few-shot** 방식을 사용했습니다.
- **통합 처리:** [문장 추출 + 카테고리 분류 + 중요도 점수]를 하나의 프롬프트에서 처리하여 파이프라인 속도 최적화.
- **JSON 강제:** 출력을 JSON 리스트 형식으로 고정하여 백엔드 서버와의 연동 편의성 극대화.

## 4. 데이터 성과
- **처리량:** 실물 가정통신문 기반 데이터 약 100여 개 분석 완료.
- **결과물:** `extracted_results.json` 생성 (베이스라인 확보).
- **정확도:** 목표 F1-Score 0.75 달성 중.

## 5. 입출력 규격 (Taesu's Schema Alignment)
태수님이 정의한 `TodoItem` 형식과 100% 일치하도록 설계되었습니다.

```json
[
  {
    "category": "준비물",
    "text_ko": "개인용 물병 및 실내화 지참",
    "due_date": "2024-05-15",
    "importance": 0.9,
    "text_vi": ""
  }
]
