# is_todo 라벨링 기준 가이드

**담당**: 윤정  
**목적**: 모델이 낮은 confidence를 부여하는 누락 패턴을 보강하기 위한 라벨링 기준 문서화  
**대상 파일**: `v2.1_notices_galsan.jsonl` 및 찬영님 제공 데이터

---

## 핵심 원칙

> **학부모가 이 문장을 읽고 뭔가 해야 하는가?**
>
> YES → `is_todo: true`  
> NO (정보 전달, 인사, 배경 설명) → `is_todo: false`

---

## 기존 기준 (v2.1 기준, 유지)

| 카테고리 | 키워드 | 예시 |
| --- | --- | --- |
| 일정 | 신청, 참여, 등록, 접수 + "주시기 바랍니다" | "기한 내 신청하여 주시기 바랍니다." |
| 준비물 | 지참, 준비물, 가져오, 챙겨, 개인물 | "개인용 이어폰을 지참해 주세요." |
| 제출 | 제출, 동의서, 신청서, 회신, 서명, 절취선 | "동의서를 절취하여 제출해 주십시오." |
| 비용 | 납부, 입금, 급식비, 교재비 | "5,000원을 납부해 주시기 바랍니다." |
| 건강·안전 | 예방접종, 건강검진, 마스크, 코로나, 안전수칙, 금지 | "마스크 착용을 의무화합니다." |
| 기타 | 협조, 동참, 설문, QR | "설문에 참여해 주시기 바랍니다." |

## 신규 추가 기준 (모델 누락 패턴 보강)

현재 모델 confidence가 0.05 미만으로 전부 컷되는 패턴들. 아래 기준으로 `is_todo: true` 추가 라벨링 필요.

### 1. 시간 정보 (운영시간·행사시간) — score 0.008

**기준**: 학부모가 참석하거나 맞춰야 할 시간 정보가 포함된 경우

```
is_todo: true 예시
- "운영시간 오전 10:00 ~ 12:00 (2시간)"
- "운영시간: 14:00 ~ 16:00"
- "행사 시간: 오후 2시 ~ 4시"
- "접수 시간: 09:00 ~ 17:00"

is_todo: false 예시
- "학교 운영 시간은 오전 9시부터입니다." (일반 안내, 행동 불필요)
- "19:00 ~ 20:00" (시간만 단독 줄, 맥락 없음)
```

### 2. 신청 방법 (신청방법·접수방법·참가방법) — score 0.043

**기준**: 학부모가 따라야 할 신청 절차가 설명된 경우 (URL 포함 여부 무관)

```
is_todo: true 예시
- "신청방법 : 통합예약시스템 (http://www.dge.go.kr/yeyak/main.do)"
- "신청방법: 학교 홈페이지 접속 후 온라인 신청"
- "접수방법: 담임 선생님께 직접 제출"
- "참가방법: QR코드 스캔 후 신청서 작성"
- "온라인을 통한 사전예약 후 방문"

is_todo: false 예시
- "신청 관련 문의: ☎031-627-7916" (문의처 안내만, 행동 아님)
```

### 3. 신청 기간·마감 기한 (신청기간·접수기간) — score 0.043

**기준**: 기간/마감이 명시되어 학부모가 그 안에 행동해야 하는 경우

```
is_todo: true 예시
- "신청기간 : 매월 1일 09:00 ~ 3일 13:00까지"
- "신청 기간: 4월 20일(월) ~ 4월 25일(금)"
- "접수 기간: 3월 6일(월) ~ 3월 17일(금) 정기 모집"
- "기한 내 신청하여 주시기 바랍니다."
- "~ 5월 2일까지 신청 완료해 주세요."

is_todo: false 예시
- "2026학년도 1학기 운영 기간: 3월 ~ 7월" (운영 기간 안내만)
- "방학 기간: 7월 25일 ~ 8월 19일" (학부모 행동 없음)
```

### 4. 기타 안내사항 (준수사항·금지사항) — score 0.231

**기준**: 학부모 또는 학생이 지켜야 할 규칙·금지사항이 포함된 경우

```
is_todo: true 예시
- "기타 안내사항 | 음식물 반입 금지, 개인 방역지침 준수"
- "기타 안내사항: 현장 당일 취소 불가"
- "주의사항: 안전모 착용 필수"
- "개인 방역지침(마스크 착용, 손소독)을 반드시 지켜주세요."

is_todo: false 예시
- "기타 문의사항은 담임 교사에게 연락 바랍니다." (문의처 안내)
- "자세한 사항은 학교 홈페이지를 참고하세요." (참고 안내)
```

### 5. 표(table) 행 — score 0.008~0.043

**기준**: 표 헤더·구분행은 false, 내용 행 중 행동을 요구하는 것은 true

```
is_todo: true 예시
- "스크린 사격 | 스포츠 클라이밍 | VR 체험" (참여 프로그램 목록 → 학부모 선택 필요)
- "1회 | 4월 18일(토) | 대구 ○○체육관" (참석 일정)

is_todo: false 예시
- "프로그램 | 일시 | 장소" (표 헤더, 내용 없음)
- "구분 | 내용 | 비고" (구분 행)
```

## is_todo: false 확정 패턴 (건드리지 말 것)

아래는 어떤 형태로 와도 false:

- 인사말: "안녕하십니까", "안녕하세요", "감사드립니다"
- 서명·날짜: "서울갈산초등학교장", "2026. 4. 18."
- 배경 설명만: "~을 운영하고 있습니다", "~을 안내드립니다"
- 문의처: "☎ 02-0000-0000", "담당: 교무부장"
- URL 단독 줄: "http://...", "www...."
- 공익 안내: "자살예방상담전화 1393", "청소년상담전화 1388"

## 라벨링 작업 순서

1. 찬영님 제공 1,000개 데이터 수신
2. `preprocess_txt_to_jsonl.py` 로 전처리 (`python file/preprocess_txt_to_jsonl.py --input_dir data/...`)
3. 이 가이드 기준으로 `is_todo` 수동 검토 (특히 신규 패턴 5종)
4. `train_koelectra.ipynb` 재실행 (v2.1 데이터 + 신규 데이터 합산)
5. F1 ≥ 0.75 달성 여부 확인 후 `checkpoints/koelectra-binary/` 교체
