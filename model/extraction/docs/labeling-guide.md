## v3.2 기준 (현행 — 2026-05-07 ~)

> **핵심 원칙**: 학부모가 이 문장을 읽고 **직접 행동하거나 반드시 인지해야 할 핵심 정보**인가?
>
> YES (6개 카테고리 해당) → `is_todo: true`  
> NO (배경 설명·인사·학교 수행 안내) → `is_todo: false`

### 구현 파일

- 라벨링 스크립트: `model/extraction/file/is_todo_label.py`
- 입력: `data/train/v3.1_dual_labeled.jsonl`
- 출력: `data/train/v3.2_dual_labeled.jsonl`

```bash
# 기본 실행 (기본 경로 사용)
python file/is_todo_label.py

# 경로 명시 + 검수용 이유 필드 포함
python file/is_todo_label.py \
  --input  data/train/v3.1_dual_labeled.jsonl \
  --output data/train/v3.2_dual_labeled.jsonl \
  --with_reason
```

### 판별 순서

```
1. is_title=True  →  제목 전용 규칙 (액션형/일정형 → True, 공지형 → False)
2. FALSE 조건 체크  →  해당하면 즉시 False (노이즈 조기 제거)
3. TRUE 조건 체크   →  7개 카테고리 중 하나라도 해당하면 True
4. 기본값 False
```

### is_todo=True 기준 (6개 카테고리)

#### CAT1. 일정

학부모가 인지하고 스케줄을 조정해야 할 정보.

| 유형 | 예시 | 판정 |
| --- | --- | --- |
| 일시·장소 헤더 | `일시: 2026년 5월 28일(목)`, `3. 장소: 해운대문화회관` | ✅ True |
| 설문·신청 기간 | `설문 기간: 2026. 4. 6.(월) ~ 4. 10.(금)` | ✅ True |
| 날짜 + 학사 행사 | `5월 4일(월)은 본교 재량휴업일입니다.` | ✅ True |
| 우천 시 변경 | `우천 시 장소를 강당으로 변경합니다.` | ✅ True |
| 세부 타임테이블 | `08:50 - 09:00 인원 점검 및 버스 탑승` | ❌ False |
| 운영 기간 안내 | `1학기 운영 기간: 3월 ~ 7월` | ❌ False |

#### CAT2. 준비물

학부모가 챙겨야 할 물품, 복장, 반입 금지 안내.

| 유형 | 예시 | 판정 |
| --- | --- | --- |
| 준비물 헤더 | `준비물: 실내화, 개인 물병` | ✅ True |
| 지참 요청 | `개인 물병을 지참해 주시기 바랍니다.` | ✅ True |
| 구체적 물품 + 행동 | `체육복을 착용하고 오세요.` | ✅ True |
| 반입 금지 | `음식물 반입 금지` | ✅ True |

#### CAT3. 제출

신청서·동의서 제출, 서명·날인, 설문 응답, 온라인 신청.

| 유형 | 예시 | 판정 |
| --- | --- | --- |
| 서류 + 마감 | `참가 신청서를 5월 7일(목)까지 제출해 주시기 바랍니다.` | ✅ True |
| 신청 방법 | `신청방법: 부산광역시교육청 통합예약포털` | ✅ True |
| 서명란·체크박스 | `보호자 서명: ___`, `□ 참석 / □ 불참` | ✅ True |
| 참석·불참 형식 | `참석 또는 불참 (사유: 구체적으로 적기)` | ✅ True |
| 온라인 설문 | `설문 응답 링크: http://...` | ✅ True |

#### CAT4. 비용

납부해야 할 금액, 입금 방법, CMS, 수익자 부담 경비.

| 유형 | 예시 | 판정 |
| --- | --- | --- |
| 비용 헤더 | `소요경비: 버스비 29,000원, 보험료 10,000원` | ✅ True |
| 납부 요청 | `5월 15일까지 납부해 주시기 바랍니다.` | ✅ True |
| CMS 자동이체 | `CMS 자동이체 잔액을 확인해 주세요.` | ✅ True |
| 수익자 부담 경비 | `수익자 부담 경비: 35,000원` | ✅ True |
| 지원금 구성 내역 | `지원금 산출 근거: 국비 50%, 지방비 50%` | ❌ False (행정 안내) |

> ⚠️ **v3.1과 다른 점**: v3.1에서는 "수익자 부담금"이 `F6_INFO_ONLY`로 False 처리됐으나, v3.2에서는 학부모가 납부해야 할 금액이므로 **True**로 변경.

#### CAT5. 건강·안전

마스크 착용, 발열 체크, 등교 금지, 안전 지침.

| 유형 | 예시 | 판정 |
| --- | --- | --- |
| 방역 수칙 | `마스크 착용을 필착해 주시기 바랍니다.` | ✅ True |
| 등교 금지 | `발열 시 등교를 금지합니다.` | ✅ True |
| 안전 교육 | `안전 수칙을 반드시 지켜 주세요.` | ✅ True |

#### CAT6. 기타

급식 여부, 도시락, 방과후·돌봄 신청, 봉사자 모집.

| 유형 | 예시 | 판정 |
| --- | --- | --- |
| 급식 없음 안내 | `당일 급식 없음 → 도시락 지참` | ✅ True |
| 방과후 신청 | `방과후학교 수강 신청을 받습니다.` | ✅ True |
| 돌봄 신청 | `돌봄교실 참여 수요조사서를 제출해 주세요.` | ✅ True |
| 급식 운영 결어 | `급식 운영에 대한 관심과 협조 감사드립니다.` | ❌ False (결어) |

### is_todo=False 확정 패턴

#### F1. 표 헤더 단독 줄

줄 전체가 카테고리 레이블인 경우 (항목 / 구분 / 성명 / 장소 등 단독).

#### F2. 숫자·기호만, 세부 타임테이블

- `①②` 단독, `1.` 단독, `---` 구분선
- `08:50 - 09:00 인원 점검...` (HH:MM–HH:MM 형태로 시작하는 프로그램 세부 일정)

#### F3. 발신일·발신자·연락처·주소

- `2026. 5. 7.` (날짜만), `서대구초등학교장`, `Tel: 051-000-0000`, 도로명 주소

#### F4. 의례적 인사말·결어

- `학부모님 안녕하십니까`, `감사드립니다`, `기원합니다`
- `학부모님 댁내 두루 평안하시길 바랍니다.`
- `많은 관심과 참여 부탁드립니다.` (추상적 협조 요청, 구체적 행동 없음)

#### F5. 행사 취지·교육 효과·배경 설명

- `~을 도모하고자`, `기대 효과`, `~이번에 마련`, `목적은 ~입니다`

#### F6. 학교·교사 수행 행동

- `본교에서 실시합니다`, `담임이 안내할 예정입니다`
- 학교가 주어이고 완결 서술동사로 끝나는 문장

#### F7. 개인정보 수집·처리 방침

- `수집 목적`, `보유 기간`, `개인정보 처리 방침`, `제3자 제공`

### 제목(is_title=True) 전용 규칙

제목 문장은 일반 CAT 규칙을 적용하지 않고 별도 3분류로 판별한다.

| 유형 | 예시 | is_todo |
| --- | --- | --- |
| **액션형** — 신청/납부/제출/모집/조사 포함 | `2학년 현장체험학습 참가 신청`, `방과후 신청 안내`, `납부 안내` | ✅ True |
| **일정형** — 재량휴업/단축수업/조기하교 포함 | `재량휴업일 안내`, `단축수업 안내` | ✅ True |
| **공지형** — 위 키워드 없는 일반 안내 | `체육대회 안내`, `여름방학 안내`, `학교 규칙 안내` | ❌ False |

## v2.1 기준 (구버전 — 초기)

> 수동 라벨링 기준. 모델이 낮은 confidence를 부여하는 누락 패턴 보강 목적.

**핵심 원칙**: 학부모가 이 문장을 읽고 뭔가 해야 하는가?

| 카테고리 | 키워드 |
| --- | --- |
| 일정 | 신청, 참여, 등록, 접수 + "주시기 바랍니다" |
| 준비물 | 지참, 준비물, 가져오, 챙겨, 개인물 |
| 제출 | 제출, 동의서, 신청서, 회신, 서명, 절취선 |
| 비용 | 납부, 입금, 급식비, 교재비 |
| 건강·안전 | 예방접종, 건강검진, 마스크, 코로나, 안전수칙, 금지 |
| 기타 | 협조, 동참, 설문, QR |

**신규 보강 패턴 5종** (v3.1 데이터 증강으로 이어진 항목):

1. 시간 정보 (운영시간·행사시간) — `운영시간: 14:00 ~ 16:00`
2. 신청 방법 (신청방법·접수방법·참가방법) — `신청방법: 학교 홈페이지 접속 후 온라인 신청`
3. 신청 기간·마감 기한 (신청기간·접수기간) — `신청기간: 4월 20일 ~ 4월 25일`
4. 기타 안내사항 (준수사항·금지사항) — `음식물 반입 금지, 개인 방역지침 준수`
5. 표 행 — 헤더는 False, 참여 일정·선택 항목은 True

## 작업 순서 (v3.2 이후)

1. `is_todo_label.py` 실행 → `v3.2_dual_labeled.jsonl` 생성
2. `--with_reason` 옵션으로 `label_reason` 필드 포함 출력 후 이상 샘플 검수

4. `train_koelectra.ipynb` 재실행 (v3.2 데이터 적용)
5. val split 및 unseen galsan 기준으로 F1·Recall 비교
