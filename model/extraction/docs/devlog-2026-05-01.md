## 2. 기호 정제 로직 전면 교체

### 문제

기존 `_SYMBOL_PATTERN`은 30여 종의 불릿·화살표 기호만 하드코딩으로 제거했음.  
실제 데이터에는 `|`(45,041회), `～`(44,406회), `☎`, PUA 문자 등 수백 종의 기호가 잔류.

### 해결

2단계 정제 파이프라인으로 교체.

**1단계 — `_NORMALIZE_TABLE` (변환)**

| 원본 | 변환 |
|---|---|
| `'` `'` | `'` |
| `"` `"` | `"` |
| `「」` `『』` `｢｣` | `"` |
| `【】` `〔〕` | `()` |
| `–` `—` | `-` |
| `～` `∼` | `~` |
| `，` | `,` |
| `×` | `x` |
| `…` | `...` |
| `￦` | 제거 |

**2단계 — `_SYMBOL_REMOVE_RE` (whitelist 제거)**

```python
# 허용 문자: 한글 / 영숫자 / . , ! ? ( ) : / % @ ~ & _ - ' "
_SYMBOL_REMOVE_RE = re.compile(
    "[^가-힣㄰-㆏a-zA-Z0-9 \\t.,!?():/%@~&_\\-'\"]"
)
```

허용 목록 외 모든 문자(불릿, 화살표, 체크박스, 원형숫자, PUA 등)를 공백으로 대체.

## 3. 날짜 분절 버그 수정

### 문제

한국식 날짜 표기(`2026.~11.30.`)가 마침표마다 문장이 쪼개져 아래처럼 3개 레코드로 분리됨.

```jsonl
{"text": "급식중단기간(61일간): 2026.", ...}
{"text": "~ 11.", ...}
{"text": "30.(정확한 일정은 추후 공지) 4.", ...}
```

**원인**: `join_broken_lines()`가 마침표로 끝나는 줄을 문장 종결로 처리(규칙 3)하고, `_simple_split()`이 모든 마침표 뒤에서 분리.

### 해결 — `join_broken_lines()` 규칙 0 추가

```python
# 규칙 0: 숫자마침표로 끝나는 줄 → 공백으로 이어줌 (날짜 분절 복원)
text = re.sub(r"(\d+\.)\n", r"\1 ", text)
```

`2026.\n~ 11.\n30.(정확한 일정은 추후 공지)` → `2026. ~ 11. 30.(정확한 일정은 추후 공지)`

### 해결 — `_simple_split()` 2글자 lookbehind 적용

```python
# 수정 전: 마침표 앞 한 글자만 확인 → . 자체는 digit 아니므로 항상 통과
r"(?<!\d)(?<=[.!?])\s+"

# 수정 후: 마침표 포함 두 글자(숫자+마침표) 확인
r"(?<!\d\.)(?<=[.!?])\s+"

# 목록 번호(1~9. 한글)에서만 분리
r"|\s+(?=[1-9]\.\s+[가-힣])"
```

| 입력 | 수정 전 | 수정 후 |
|---|---|---|
| `2026. ~ 11. 30.(추후 공지) 4. 다음 항목...` | 4개 조각 | 2개 (날짜 묶음 + 목록 항목) |
| `안내사항 1. 제출기한 2. 서류 제출` | 불규칙 분리 | `1.` `2.` 앞에서 정확히 분리 |
| `행사기간: 2026. 5. 1. ~ 5. 31.` | 6개 조각 | 1개 (날짜 범위 보존) |

### 결과

문장 수: 46,046개 → **35,219개** (날짜 조각 통합으로 감소)

## 4. auto_label.py — 규칙 기반 is_todo 초안 라벨러

### 배경

v3_school.jsonl 35,219개 문장이 모두 `is_todo: false` (기본값)로 생성됨.  
KoELECTRA 학습을 위해 양성 라벨이 필요하지만 전체 수동 라벨링은 시간 소모가 큼.  
→ 규칙 기반으로 초안 라벨을 먼저 부여하고, 이후 Gemini API 보조 또는 수동 검수로 보완하는 방향 채택.

### 판정 로직

**판정 순서**: FALSE 조건 먼저 → TRUE 조건 OR 체크 → 기본값 False

**FALSE 조건 8종**

| 코드 | 설명 | 예시 |
|---|---|---|
| F1 | 표 헤더 / 구분자 | `항목`, `담당`, `기간` (단독) |
| F2 | 소제목 / 번호만 | `1.`, `가.` (단독) |
| F3 | 발신일 / 서명 / 연락처 | `2026. 5. 1.`, `서울갈산초등학교장` |
| F4 | 개인정보 안내문 | `수집 목적`, `보유 기간` |
| F5 | 인사말 / 결어 | `안녕하십니까`, `안내드립니다.` |
| F6 | 총액 / 환불 정보 | `환불 규정`, `지원금 내역` |
| F7 | 운영 방침 / 취지 설명 | `도모하기 위해`, `기대 효과` |
| F8 | 학교 측 수행 행동 | `본교에서는 ~ 운영합니다` |

**TRUE 조건 7종**

| 코드 | 설명 | 예시 |
|---|---|---|
| T1 | 마감일 + 액션 동사 | `5월 31일까지 제출해주세요` |
| T2 | 양식 작성 칸 | `보호자 성명:`, `□ 동의` |
| T3 | 준비물 목록 | `준비물: 실내화, 도시락` |
| T4 | 안전·건강 지침 | `발열 체크 후 등교 금지` |
| T5 | 일정 인지 (날짜 동반) | `5월 5일(월)은 재량휴업일` |
| T6 | 학부모 직접 액션 | `잔액 확인`, `CMS 자동이체` |
| T7 | 요청형 종결 어미 | `~해주세요`, `~바랍니다` |

### v3_labeled.jsonl 결과

| | 건수 | 비율 |
|---|---|---|
| is_todo=True (할 일) | 3,387 | 9.6% |
| is_todo=False (노이즈) | 31,832 | 90.4% |

**매칭 이유 분포 (상위 5)**

| reason | 건수 |
|---|---|
| no_match (기본 False) | 29,167 |
| T7_request_ending | 1,429 |
| F4_form_guidance | 1,281 |
| T1_deadline_action | 1,058 |
| F5_greeting_sign | 450 |

### 검수 시 주의

- `T7_request_ending`: `"학부모님 댁내 두루 평안하시길 바랍니다."` 같이 요청형 어미지만 할 일이 아닌 케이스 포함됨. 이 reason 구간 집중 검수 필요.
- `T4_safety_health`: 유행주의보 발령 배경 설명 문장이 일부 포함될 수 있음.

### 사용법

```bash
# 초안 라벨링 (label_reason 포함)
python file/auto_label.py \
  --input  data/v3_school.jsonl \
  --output data/v3_labeled.jsonl \
  --with_reason
```
