## 1. `02_evaluate_compare.ipynb` 상세 설명

### 노트북 목적

`scripts/evaluate_compare.py`가 생성한 JSON 결과 파일을 불러와 **Simple(TF-IDF + LR)과 KcELECTRA 두 모델의 성능을 시각적으로 비교**하는 노트북이다. GPU 없이 CPU에서 실행 가능하며, 시각화 결과물은 `data/` 폴더에 PNG로 저장된다.

### 실행 전 필수 조건

| 조건 | 파일 |
|------|------|
| 베이스라인 학습 완료 | `checkpoints/simple_tfidf_logreg.pkl` |
| 데이터 분할 완료 | `data/split_v1.csv` |
| 평가 스크립트 실행 완료 | `data/eval_results_simple.json`, `data/eval_results_kcelectra.json` |
| KcELECTRA 파인튜닝 완료 | `checkpoints/kcelectra-category/` |

### 셀별 구조 요약

| 셀 | 역할 | 핵심 내용 |
|----|------|-----------|
| 0 | Markdown 안내 | 실행 전 체크리스트, 노트북 목적 설명 |
| 1 | 패키지 설치 | `matplotlib`, `seaborn`, `pandas`, `scikit-learn` |
| 2 | 임포트 및 설정 | OS별 한글 폰트 설정 (Windows: 맑은고딕 / macOS: AppleGothic / Linux: NanumGothic), `BASE_DIR`, `LABELS` 정의 |
| 3 | 결과 JSON 로드 | `eval_results_simple.json`, `eval_results_kcelectra.json` 로드. 파일 없으면 경고 출력 후 빈 dict 반환 |
| 4 | 베이스라인 직접 평가 (폴백) | `simple_res` JSON이 없을 경우 `src/classifier_simple.py`의 `evaluate()` 직접 호출 |
| 5 | Macro F1 막대 그래프 | 두 모델의 전체 Macro F1 비교. "Simple + 5%" 채택 기준선 표시. `compare_macro_f1.png` 저장 |
| 6 | Per-class F1 막대 그래프 | 6개 카테고리별 F1 점수 비교. `compare_per_class_f1.png` 저장 |
| 7 | Confusion Matrix 비교 | 두 모델의 혼동행렬을 나란히 시각화. `compare_confusion_matrix.png` 저장 |
| 8 | 성능 요약 테이블 | Macro F1·Precision·Recall 및 카테고리별 F1 정리. Δ 기준으로 채택 권고 출력. `eval_comparison_summary.csv` 저장 |
| 9 | 레이더 차트 | 6개 카테고리 F1을 육각형으로 시각화. `compare_radar_f1.png` 저장 |

## 3. 주요 발견 — KcELECTRA F1 전 카테고리 0.0

### 문제 상황

KcELECTRA의 모든 카테고리 F1이 0.0이다. 이는 모델이 전혀 학습되지 않았거나, 추론 시 라벨 매핑에 문제가 있다는 신호다.

### 원인 추정 (우선순위순)

1. **파인튜닝 미완료** — `checkpoints/kcelectra-category/`에 저장된 체크포인트가 `01_train_kcelectra.ipynb` 완전 실행 전의 것일 가능성 (학습 전 초기 가중치)
2. **라벨 인덱스 불일치** — 학습 시 인코딩한 라벨 순서와 추론 시 `LABELS` 리스트 순서가 다를 경우 전 클래스 F1이 0에 수렴할 수 있음
3. **데이터 불일치** — 학습에 사용한 `split_v1.csv`와 평가에 사용한 CSV가 다른 버전일 가능성

### 확인 방법

```python
# evaluate_compare.py 실행 후 KcELECTRA 예측 분포 확인
import json
with open("data/eval_results_kcelectra.json") as f:
    res = json.load(f)
print(res.get("confusion_matrix"))  # 특정 행/열에만 집중되면 라벨 매핑 문제
```
