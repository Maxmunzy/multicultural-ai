### 15-2. Simple 기준값이 0.8116 → 0.7590으로 떨어진 이유

**Simple 모델 자체가 나빠진 게 아니다. 평가한 데이터셋이 달라졌기 때문이다.**

| 항목 | v3 데이터 (split_v5_20260505.csv) | v3_1 데이터 (split_v3_1_20260509.csv) |
|---|---|---|
| 전체 데이터 | 4,992행 | 15,948행 |
| **기타 비율** | **15.8%** | **46.5%** |
| 기타 test 건수 | 약 79건 | 약 740건 |

**원인 메커니즘:**

Macro F1은 클래스 크기와 무관하게 6개 클래스를 단순 평균한다.

```
Macro F1 = (일정 F1 + 준비물 F1 + 제출 F1 + 비용 F1 + 건강·안전 F1 + 기타 F1) / 6
```

- `기타`는 의미가 가장 모호하여 항상 F1이 가장 낮은 클래스 (v3에서도 Simple 기타 F1 = 0.5963)
- v3_1 데이터에서 `기타`가 **15.8% → 46.5%** 로 급증 → test set도 기타 비중이 매우 높아짐
- Simple의 `class_weight="balanced"`는 학습 불균형을 보정하지만, **기타의 의미적 모호함** 자체는 해결 불가
- 기타 F1이 낮은 상태에서 test set 절반 가까이가 기타이므로 Macro F1 전체가 끌려 내려감

**이것은 정상적인 현상이며, KcELECTRA v3_2가 유리해지는 이유이기도 하다.**

KcELECTRA v3_2(셀 6)는 train 분포에서 동적으로 계산된 클래스 가중치를 CrossEntropyLoss에 적용한다.  
기타 46.5% → 기타 가중치는 낮아지고, 준비물(2.8%)·비용 등 소수 클래스 가중치는 높아진다.  
Simple보다 이 불균형을 훨씬 정교하게 처리할 수 있다.

> **결론:** Simple 0.8116 → 0.7590 하락은 모델이 나빠진 것이 아니라,  
> 훨씬 어려운 데이터(기타 46.5% 극단 불균형)에서 평가했기 때문이다.  
> 같은 이유로 KcELECTRA v3_2의 클래스 가중치 전략이 이 데이터에서 더 큰 효과를 낼 것으로 기대된다.
