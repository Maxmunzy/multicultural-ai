## 5. 현재 결과 해석

### 잘 된 점
- KcELECTRA가 **전 카테고리에서 Simple 이상** 성능 달성 (하락 없음)
- **비용** 카테고리: +10.95%p — 금액, 납부, 안내 등 비용 관련 표현을 전이학습 모델이 잘 포착
- **기타** 카테고리: +7.04%p — 불명확한 공지도 KcELECTRA가 더 잘 분류
- **Macro Recall** +6.66% — 5% 목표 초과 달성, 모델이 더 균형 있게 클래스를 커버
- v2 대비 KcELECTRA 성능이 0.6938 → 0.8545로 대폭 향상 (데이터 7배 증가 효과)

### 아쉬운 점
- **Macro F1 +4.29%** — 목표치 5%에 0.71%p 미달
- **일정·준비물** 카테고리 개선 폭 미미 (~)
  - 일정: Simple이 이미 0.88로 높아서 개선 여지가 좁음
  - 준비물: test 22건에 불과해 1~2건 오분류가 수치에 크게 영향
- **기타** 카테고리가 양 모델 모두 낮음 (0.60 / 0.67) — 정의 자체가 모호한 클래스

### 우선순위 3 — Simple 앙상블 *(내일, 빠른 방법)*

목표가 5% 이상 차이라면, KcELECTRA + Simple 소프트 투표 앙상블로 즉시 달성 가능:

```python
# evaluate_compare_v3_20260505.py에 추가
def ensemble_predict(texts, kc_model, simple_model, weight_kc=0.7):
    kc_probs  = kc_model.predict_proba(texts)      # (N, 6)
    s_probs   = simple_model.predict_proba(texts)   # (N, 6)
    combined  = weight_kc * kc_probs + (1 - weight_kc) * s_probs
    return combined.argmax(axis=1)
```

> 앙상블은 시연용이 아닌 최종 서비스 모델 확정 전에 사용하는 방법.
