---

## 요약

v3_1 데이터(15,948행) 기준으로 beomi/kcelectra-base 파인튜닝 모델(KcELECTRA v3_2) 평가를 완료했다.

Macro F1 기준 Simple 베이스라인(0.7590) 대비 **+0.0784** 향상(0.8374)을 달성했으나, 16 에포크 학습 후 검증셋 기준으로 이미 수렴(best_val_f1=0.8254)했다. 카테고리별 F1을 분석한 결과, Macro F1을 실제로 끌어내리는 주원인은 흔히 지목되는 "기타"가 아니라 **건강·안전(F1 0.8034, Precision 0.7402)**이었으며, 그 배경에는 기타-건강·안전 사이의 레이블 경계 기준 부재라는 구조적 문제가 있다.

## v3_2 모델 자체의 성능 한계 분석 (1~3순위)

아래 순위는 v3_2 confusion matrix와 per-class F1에서 직접 도출한 것으로, v1_2·v2_2와의 버전 비교가 아닌 **v3_2가 수렴한 지점에서의 병목**을 기준으로 한다.

---

### 1순위 — 기타-건강·안전 레이블 경계 기준 부재

Confusion Matrix에서 가장 큰 단일 오분류가 **기타→건강·안전 61건**이다.

```
기타 → 건강·안전: 61건  ← 전체 행렬 대각선 제외 최대값
건강·안전 → 기타: 21건  ← 역방향 오분류도 존재
```

이 양방향 혼동이 건강·안전의 Precision을 **0.7402(6개 중 최저)**까지 끌어내리며, 결과적으로 건강·안전 F1이 0.8034(최저)로 Macro F1 전체를 하방 압박한다.

문제의 본질은 "기타 데이터 다양성 부족"이 아니라, **기타와 건강·안전을 구분하는 라벨링 기준 자체가 없다**는 것이다. "수영 수업 안전 주의사항 안내"처럼 두 카테고리 모두에 해당할 수 있는 문장에 대해 기준이 없으면, 라벨러마다 다르게 분류하고 그 모호함이 학습 데이터에 섞인다.

---

### 2순위 — 기타 클래스 불균형 (46.5%)

기타가 test set의 **46.5%** (741/1,593건)를 차지한다.

```
클래스 가중치:
  기타:     0.3587  (가장 낮음 = 가장 많은 샘플)
  준비물:   5.9399  (가장 높음 = 가장 적은 샘플)
  비용:     3.1411
  건강·안전: 1.2378
  일정:     1.3702
  제출:     0.8418
```

weighted loss를 적용했음에도 이 정도 불균형이면 모델은 기타 패턴을 과도하게 내재화하고, 나머지 5개 카테고리 학습이 상대적으로 빈약해진다.

"기타 데이터 다양성 부족"이라는 표현은 사실 이 불균형 문제에 더 가깝다. 데이터가 부족해서가 아니라, **기준 없이 쌓인 기타 데이터가 너무 많아서** 문제다.

---

### 3순위 — 기타 개념 자체의 모호함

기타가 특정 카테고리 하나가 아닌 **전체 카테고리로 고루 오분류**된다.

```
기타 → 건강·안전: 61건
기타 → 제출:      28건
기타 → 비용:      11건
기타 → 일정:      10건
기타 → 준비물:     4건
```

반대로 다른 카테고리도 기타로 흘러들어온다.

```
제출     → 기타: 54건 (제출 오분류 중 85.7%)
일정     → 기타: 22건 (일정 오분류 중 62.9%)
건강·안전 → 기타: 21건
비용     → 기타: 10건
```

기타는 "그 외 모든 것"이라는 정의상 명확한 의미 경계가 없다. 모델이 학습할 결정 경계(decision boundary) 자체가 불분명하다. 1순위와 연결되는 근본 원인이다.

---

### 비용(F1 0.8095)에 대하여

비용은 건강·안전과 달리 단일 원인이 아닌 **복합 문제**다.

```
비용 → 기타:  10건  (recall 문제)
기타 → 비용:  11건  (precision 문제)
```

기타-비용 간 양방향 혼동이 존재하지만 규모가 작다. 동시에 test가 **84건**밖에 없어 수치 신뢰도 자체가 낮다(1건 오분류 = F1 약 ±1.2%p). 순수 데이터 양 문제라기보다 **경계 혼동 + 소규모 데이터가 겹친 복합 원인**으로 판단한다.

## 결론 (발표/보고서용)

> "KcELECTRA v3_2의 카테고리별 F1을 분석한 결과, 기타(F1 0.8479)는 6개 카테고리 중 3위로 성능 한계의 직접 원인이 아니었다. Macro F1을 실제로 끌어내리는 건 건강·안전(F1 0.8034, Precision 0.7402)이며, 그 원인은 기타→건강·안전 오분류 61건(Confusion Matrix 내 대각선 제외 최대값)으로 확인된다. 이는 두 카테고리 사이의 라벨링 기준이 부재하여 학습 데이터에 경계 모호함이 섞인 결과다. 2순위는 기타가 test set의 46.5%를 차지하는 클래스 불균형, 3순위는 기타 개념 자체의 모호함으로, 이 세 요인 모두 v3_2 Confusion Matrix와 per-class F1에서 직접 도출된 v3_2 모델 자체의 수렴 지점 한계다."
