## 1. 아이디어 핵심 내용 (공공데이터 활용 적정성)

### 1-1. 해결하려는 사회 문제

한국의 다문화 초등학생은 2025년 기준 **11만 7천 명**으로, 2012년 대비 3.5배 증가했습니다. 이들의 부모 중 상당수는 베트남(30.5%), 중국(16.1%), 필리핀(12.4%) 등 외국 출신 결혼이민자이며, **한국청소년정책연구원 다문화청소년패널조사 2023년 2기 5차 조사(N=1,750)** 에 따르면 결혼이민자 학부모의 한국어 쓰기 평균 점수는 5점 만점에 3.25점으로 4개 영역 중 가장 낮으며, 읽기는 3.52점입니다. 쓰기 취약 비율(3점 이하)은 18.7%, 읽기 취약 비율은 10.2%에 달합니다.

학교에서 가정으로 보내는 **가정통신문**은 글로 된 문서입니다. 읽기 능력이 취약한 결혼이민자 학부모는 학교 일정, 납입금, 준비물, 동의서 제출 기한 등 핵심 정보를 놓치게 됩니다. 설상가상으로 가정통신문에 사용되는 어휘의 **37%가 표준 한국어 교재에 없는 행정·교육 전문 어휘**이며(오지연, 2017), 기존 범용 번역기(파파고, ChatGPT)는 "스쿨뱅킹", "방과후학교", "차상위계층", "나이스" 같은 용어를 정확히 번역하지 못합니다.

> **공공데이터가 이 문제를 증명합니다.** 서울특별시·인천광역시·경기도 교육청의 공공데이터는 지역별 다문화 학생 수, 가정 유형, 국적 분포를 정량적으로 보여주며, 이 데이터 없이는 문제의 규모와 지역별 불균형을 객관적으로 설명하기 어렵습니다.

### 1-2. SchoolBridge의 솔루션 개요

SchoolBridge는 기존 학부모 알림장 앱(학교종이, 하이클래스, e알리미 등)에 **API/SDK 형태로 탑재되는 가정통신문 특화 AI 엔진**입니다.

**핵심 파이프라인:**

```
HWP/PDF 입력
    ↓ Claude Haiku 4.5 (문장 정리 및 추출)
    ↓ KoELECTRA (핵심 문장 선별 · Recall 0.868)
    ↓ KcELECTRA (6개 카테고리 분류 · v3_2 Macro F1 0.8374, v4 학교알리미 국가중점데이터 증강 학습)
    ↓ NLLB-200 + 도메인 글로사리 340어+ (9개 언어 번역)
    ↓ Edge-TTS (다국어 음성 생성)
    ↓ Android 앱 (카드·체크리스트·캘린더·FCM 알림)
```

**공공데이터 기반 의사결정 (서비스 설계에 직접 반영):**

| 공공데이터가 밝힌 사실 | SchoolBridge 설계 반영 |
|---|---|
| 다문화 학생 부모 국적 상위 9개국이 73%+ 차지 | **9개 언어** (베트남어·중국어·영어·필리핀어·일본어·태국어·몽골어·러시아어·캄보디아어) 우선 지원 |
| 수도권 vs 지방 다문화 학생 수 최대 870배 격차 | 지방 소도시에서 행정 인력 없이 **자동 번역 배포** 가능한 SaaS 구조 채택 |
| 결혼이민자 한국어 쓰기 3.25/5 (4영역 최저, 취약 18.7%), 읽기 3.52/5 (취약 10.2%) | 번역 + **TTS 음성 듣기** + STT 질문 기능 → 읽기·쓰기 어려워도 이해 가능 |
| 외국인가정(부모 모두 외국인) 비중 2012년 5.3% → 2025년 29.3% | 국제결혼가정뿐 아니라 **외국인 가정 자녀**도 명시적 서비스 대상 포함 |
| 가정통신문 어휘 37% 표준 교재 없음 | 340개 이상 **도메인 글로사리** 수기 구축, 미등록 용어 자동 감지 루프 설계 |
| **학교알리미 보건·복지·학사 데이터** (교육부 국가중점데이터, #15014351) | KcELECTRA 6분류 모델 학습 데이터 **564행 증강** — 건강·안전+301행, 일정+185행, 비용+78행 → Macro F1 0.8374 대비 건강·안전 F1 향상 목표 (v4 모델) |
| **다문화청소년패널조사** 보호자 응답: 언어능력·학교생활·부모관계·진로 종단 측정값 (NYPI, 국가중점데이터, #15154775) | 페르소나 정량 보강 — 쓰기 3.25/5 (최저, 취약 18.7%), 읽기 3.52/5 (취약 10.2%) 실측 확인 + 담임교사 면담 비참여 52.1%, 학부모 교육 비참여 84.3%, 자녀 학교교육 도움 불가 49.8%로 정보격차 규모 실증 |
| **아동·청소년·청년 데이터 통합조회** (NYPI, 국가중점데이터, #15154907) | 통합조회 API 실측: 4개 조사 총 40,871건 확인 (한국아동·청소년패널 24,135건·다문화청소년패널 7,555건·한국청소년패널 6,211건·학업중단패널 2,970건) → 다문화패널 카테고리 구조 메타 탐색 완료 |

### 1-3. 공공데이터 활용이 적정한 이유

#### (1) 시장 규모 정량화 — 주관적 추정이 아닌 행정 통계

일반 스타트업이 "다문화 가정이 많다"고 주장하는 것과, 공공데이터로 "서울 영등포구 초등학교에 XX명의 다문화 학생이 다닌다"고 증명하는 것은 근본적으로 다릅니다.

- **서울특별시 다문화가정 학생 현황 통계** (data.go.kr #15046284): 25개 구별 초등·중·고 학생 수와 국제결혼/외국인가정 구분 제공 → 서비스 우선 배치 지역 선정에 직접 활용
- **경기도교육청 다문화학생현황** (data.go.kr #15077326): 경기 31개 시군별·학교급별·국가별 학생 수 → 경기도 내 행정 격차 분석

#### (2) 타겟 언어 선정 — 감이 아닌 혼인 국적 데이터

"어떤 언어를 지원할 것인가"는 비용과 직결되는 핵심 결정입니다.

- **서울특별시 외국인과의 혼인 (국적별)** (data.go.kr #15046318): 외국인 배우자의 국적별 혼인 건수 제공 → 베트남·중국·필리핀 등 상위 9개 국적이 전체 혼인의 73% 이상 커버 → **9개 언어 선정의 통계적 근거**
- **인천광역시 외국인 국적별 등록현황** (data.go.kr #15055021): 2019~2023년 추세 → 베트남·태국·카자흐스탄 등 신흥 증가 국적 조기 파악

#### (3) 행정 격차 증명 — 서비스 필요성의 핵심 근거

"학교 행정 인력이 없어서 번역 통신문을 못 보낸다"는 주장을 공공데이터로 직접 증명합니다.

- **경기도 안산시 내국인 및 외국인 현황** (data.go.kr #3069669): 안산시 읍면동별 외국인 비율 → 특정 동에서 전체 인구의 30% 이상이 외국인 → 행정 부담 극대화 지역
- **강원특별자치도 외국인 등록현황** (data.go.kr #15050501): 지방 소도시의 외국인 수 → 수도권 대비 수십 배 격차 → 지방일수록 행정 인력 부족, AI 자동화 필요성 증가
- **인천광역시 다문화 가족 통계** (data.go.kr #15105922): 구별 다문화가족 규모 → 인천 내에서도 수십 배 구간 격차 → 지역별 서비스 우선순위 설계

#### (4) AI 분류 모델 학습 — 국가중점데이터를 학습 데이터로 직접 활용

공공데이터를 단순 통계 인용에만 쓰는 수준을 넘어, **AI 모델 학습 데이터로 직접 투입**했습니다.

- **교육부 학교알리미 공개용데이터** (data.go.kr #15014351, 국가중점데이터): 보건·복지 항목(급식·보건·복지)의 실제 공지 패턴 → **건강·안전** 카테고리 301행, 학사·학생 항목(학사일정·행사)의 실제 공지 패턴 → **일정** 카테고리 185행, 재정·시설 항목(급식비·방과후학교·교복비)의 실제 공지 패턴 → **비용** 카테고리 78행 생성 (총 564행)
- **실제 구현**: `generate_schoolalimi_augment_20260525.py` → `split_v4_schoolalimi_20260525.csv` (16,512행) → `14_train_kcelectra_v4_schoolalimi_20260525.ipynb` (Colab 학습)
- **개선 목표**: KcELECTRA v3_2 최약 카테고리 건강·안전 (F1 0.8034, Precision 0.7402) → v4에서 F1 0.83+ 달성
- **법적 신뢰성**: 교육관련기관의 정보공개에 관한 특례법 기반 교육부 직접 개방 국가중점데이터

> 공공데이터를 AI 모델 학습에 직접 투입하는 것은 단순 시장 분석용 통계 활용과 근본적으로 다른 수준의 공공데이터 활용입니다. 학교 현장에서 실제 사용되는 공문 표현 패턴을 국가가 인증한 데이터로 학습하므로, 모델의 신뢰성과 검증 가능성이 일반 크롤링 데이터 대비 현저히 높습니다.

#### (6) 페르소나·사회적 가치 정량 검증 — 다문화청소년 종단 국가중점데이터

SchoolBridge의 페르소나("베트남 출신 결혼이민자 학부모, 한국어 읽기 약함")와 핵심 사회적 가치 명제("학부모 정보격차가 자녀 학교생활 적응에 영향을 미친다")는 단면 조사로도 지지되지만, 종단 데이터를 통해 인과적으로 검증하면 정책·납품 단계의 설득력이 크게 높아집니다.

- **한국청소년정책연구원_다문화청소년패널조사** (data.go.kr #15154775, 국가중점데이터): "다문화 청소년 및 보호자를 대상으로" 언어능력·이중문화경험·학교생활·부모관계·진로를 다년도 추적한 종단 패널 — SchoolBridge의 핵심 4개 주제(언어·학교생활·부모관계·진로)와 직접 대응. 실측 결과 (2023년 2기 5차, N=1,750): 학부모 한국어 쓰기 3.25/5 (최저, 취약 18.7%), 담임교사 면담 비참여 52.1%, 학부모 교육 비참여 84.3%, 자녀 학교교육 도움 불가 49.8% 확인.
- **한국청소년정책연구원_아동·청소년·청년 데이터 통합조회** (data.go.kr #15154907, 국가중점데이터): 실측 API 직접 호출로 4개 조사 총 40,871건 확인 — 한국아동·청소년패널(24,135건), 다문화청소년패널(7,555건), 한국청소년패널(6,211건), 학업중단패널(2,970건). searchKeyword='다문화' 조건으로 다문화패널 카테고리 구조(개인요인·다문화관련요인·환경요인·배경변인) 탐색 완료.

### 2-2. 공공데이터 활용의 서비스 개선 계획

#### (1) 미등록 용어 자동 감지 루프와 공공데이터 연계

현재 SchoolBridge는 번역 시 도메인 글로사리(340어+)에 없는 용어를 감지해 `unknown_terms`로 저장하는 루프를 구현했습니다. 향후 이 루프를 **교육부·교육청 공공데이터와 연계**해 신규 교육 정책 어휘(예: "늘봄학교", "학교자율시간")를 자동 수집하고 글로사리를 갱신할 계획입니다.

#### (2) 지역별 번역 수요 대시보드

공공데이터(구별 다문화 학생 수 + 학교 위치 공개 데이터)를 결합해 **지역별 번역 수요 밀도 지도**를 구축합니다. 이를 통해 교육청·지자체가 어느 학교에 서비스를 우선 배치할지 정책 결정을 지원합니다.

#### (3) 연도별 업데이트 자동화

서울시, 인천시, 경기도교육청 등의 공공데이터는 연 1회 이상 업데이트됩니다. API 연동(data.go.kr 오픈 API)으로 다문화 학생 수, 국적별 분포를 자동 갱신해 **번역 언어 우선순위와 글로사리 확장 계획**에 실시간 반영합니다.
