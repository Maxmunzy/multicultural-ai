# 공모전: https://www.ssis.or.kr/lay1/bbs/S1T67C95/A/102/view.do?article_seq=128068

■ 국가중점데이터 활용계획
[교육분야- 교육행정정보·학교알리미 개방시스템] - 일반 공공 데이터 및 국가중점데이터

▶ 데이터셋 식별 정보
  - 데이터셋명: 교육행정정보
  - 분류: 국가중점데이터 (행정안전부 지정, 교육 분야)
  - 제공기관: 교육부
  - 제공 시스템: 교육부 교육행정정보·학교알리미 개방시스템
  - 제공 방식: 파일데이터
  - 국가중점데이터 카탈로그: 
    https://www.data.go.kr/tcs/eds/selectCoreDataListView.do
  - 데이터목록 검색: "교육행정정보" 검색 시 즉시 노출
  - 핵심 구성 데이터셋: 한국교육학술정보원_학교알리미 공개용데이터
    URL: https://www.data.go.kr/data/15014351/fileData.do
    근거 법령: 교육관련기관의 정보공개에 관한 특례법 및 시행령

▶ 개방 데이터 항목 (출품작에 직접 활용되는 카테고리)
- 본 데이터는 "전국 초·중등학교의 학사·인사·예산 등의 교육행정 정보와 학생·교원현황, 학교시설 등 학교 전반의 중요한 정보"로, 교육부의 "교육행정정보·학교알리미 개방시스템"을 통해 개방됨
  ① 학사·학생: 대학진학률(졸업생의 진로현황), 수업시수, 학생현황, 
     동아리활동, 수업공개계획
  ② 재정·시설·설비: 학교시설(교사현황·학생교육활동에 필요한 
     지원시설 현황 등), 교원현황, 교육특색사업, 교복구매 유형·단가
  ③ 보건·복지: 급식, 보건, 복지 등 학교 운영 정보
- 이 데이터를 활용시에 "교육관련기관의 정보공개에 관한 특례법" 근거의 법적 신뢰성 데이터로, 본 출품작의 신뢰성·검증 가능성을 확보하는 핵심 토대 

▶ 출품작 내 활용 방식 (4단계)
  (1) 학사일정 교차 검증: KoELECTRA가 가정통신문에서 추출한 
      날짜·일정(체험학습일·방학식·졸업식·운동회 등)을 학교알리미 
      공개용데이터의 학사 항목과 교차 검증하여, 슬롯 추출 오류 
      자동 검출 (발표자료 4-1 KoELECTRA Recall 0.868의 미검출 
      11.2%p 추가 보완)
  (2) KcELECTRA 6분류 학습 데이터 보강: 발표자료 4-2의 카테고리 
      분류 모델(현재 학습 데이터 15,948건) 중 "일정"·"건강·안전" 
      카테고리 샘플을 학사·보건·복지 영역으로 확장하여 분류 정확도 
      추가 향상 (현재 Macro F1 0.8374 → 향상 목표)
  (3) 학교 공식 정보 인증: 가정통신문 발신 학교가 학교알리미 
      등록 학교인지 자동 검증 → 가짜·피싱 가정통신문 필터링 --> (3)은 안함.
  (4) 지역별 보급 우선순위 의사결정 보조: 학교알리미의 학교 단위 
      학생수 데이터와 KESS 시군구별 다문화 학생수 데이터를 결합해 
      "다문화 학생 비율 높은 학교" 자동 식별 → 우선 보급 대상 선정

▶ 사업화 확장 계획
  - 학교알리미·NEIS 양 시스템을 결합한 SchoolBridge SDK 표준화: 
    기존 알림장 앱(학교종이·하이클래스·e알리미 등)이 학사일정·
    학교 정보를 별도 DB로 관리하지 않아도 SchoolBridge SDK 호출 
    한 번으로 모든 학교 정보 자동 동기화
  - 교육부와의 협력 모델 도출: 본 데이터는 교육부 직접 개방 
    국가중점데이터로, 사업화 단계에서 교육부·각 시도교육청 
    납품 시 데이터 활용의 법적·정책적 정합성 확보
