## (1) 학사일정 교차 검증

### 개요

KoELECTRA가 가정통신문에서 추출한 날짜·일정 슬롯(체험학습일·방학식·졸업식·운동회 등)을 학교알리미 공개용데이터의 학사 항목과 교차 검증하여, 슬롯 추출 오류를 자동 검출한다.

### 배경

- KoELECTRA 슬롯 추출 Recall = 0.868 → 11.2%p 미검출 존재
- 학교알리미 학사 데이터에는 전국 학교의 실제 학사 일정(방학식·입학식·졸업식 날짜 등)이 포함되어 있어, 추출된 날짜가 해당 학교의 실제 학사 일정과 일치하는지 검증 가능

### 구현 방향 (미완)

```
1. 학교 식별: 가정통신문 발신 학교명 추출 (NER 또는 헤더 파싱)
2. 학교알리미 API 조회: 해당 학교 학사 일정 데이터 로드
3. 교차 검증: KoELECTRA 추출 날짜 vs 학교알리미 학사 일정 비교
   - 일치: 슬롯 신뢰도 ↑
   - 불일치: 오류 플래그 → 재추출 또는 경고
4. 출력: 검증된 슬롯 + 불일치 건수 통계
```

### 필요 작업

- [ ] 학교알리미 API(data.go.kr) 키 발급 및 학사 데이터 항목 확인
- [ ] 학교명 → 학교 코드 매핑 테이블 구축
- [ ] 교차 검증 로직 구현 (model/ner/ 또는 별도 validation 모듈)
- [ ] KoELECTRA 슬롯 추출 파이프라인과 통합

## (3) 지역별 보급 우선순위 의사결정 보조

### 개요

학교알리미의 학교 단위 학생수 데이터와 KESS(교육통계서비스) 시군구별 다문화 학생수 데이터를 결합하여 "다문화 학생 비율 높은 학교"를 자동 식별하고, 우선 보급 대상 학교를 선정한다.

### 배경

- 현재 공공데이터 사업계획서에는 시도·시군구 단위 다문화 학생 통계를 활용하고 있으나 (서울·경기·인천 등), **학교 단위** 세분화는 미구현
- 학교알리미는 학교별 학생수를 제공하므로, KESS 다문화 학생수와 결합하면 특정 학교의 다문화 학생 비율을 추정 가능

### 구현 방향 (미완)

```
1. 데이터 수집:
   - 학교알리미: 학교별 전체 학생수 (학교코드 기준)
   - KESS: 시군구별 다문화 학생수 (KESS 교육통계 API)
2. 결합:
   - 시군구 내 각 학교의 다문화 학생 비율 추정 (시군구 비율을 학교별로 적용)
   - 또는 직접 학교알리미 다문화 학생수 항목 활용 (해당 항목 공개 여부 확인 필요)
3. 우선순위 산출:
   - 다문화 학생 비율 상위 N개 학교 자동 추출
   - 지역별·학교급별 분류
4. 활용:
   - B2B 영업 우선 대상 학교 목록 제공
   - 교육청 협력 시 정책 지원 대상 학교 자동 선정
```

### 필요 작업

- [ ] 학교알리미 학교별 학생수 데이터 API 또는 파일 수집
- [ ] KESS API 연동 (시군구별 다문화 학생수)
- [ ] 학교 단위 다문화 학생 비율 추정 모듈 구현
- [ ] 지역별 우선순위 대시보드 또는 보고서 자동 생성 스크립트
