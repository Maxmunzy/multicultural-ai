# OLD

프로젝트 최종 구조에서 직접 실행하거나 최신 README에서 바로 참조하지 않는 과거 작업 로그, 발표 초안, 구버전 실험 산출물을 보관하는 폴더입니다.

현재 서비스 코드와 최신 모델/문서는 기존 위치에 두고, 아래 성격의 자료만 옮겼습니다.

| 경로 | 내용 |
| --- | --- |
| `docs/worklogs/` | 날짜별 작업 로그 |
| `docs/presentation_drafts/` | 발표 초안 및 중간 정리본 |
| `docs/experiments/` | 과거 정량 실험 노트와 중간 평가 문서 |
| `docs/assets/` | 과거 발표/공유용 이미지 자료 |
| `outputs/` | 보관용 중간 산출물 |
| `model/classification/` | 분류 모델 구버전 README와 delete 폴더 |
| `model/extraction/` | 주요 추출 모델 구조에 남기기 애매한 초기 실험 코드 |

보관 목적의 이동이므로, 필요한 경우 이 폴더에서 과거 실험 맥락을 다시 확인할 수 있습니다.
